Privacy policy

Last updated: 1 November 2026

This is a plain-language draft and not legal advice. It has not been reviewed by a lawyer.

1. The short version

OMNIServers runs on your own computer. Your Minecraft servers, worlds, player data, backups and console logs stay there. There is no OMNIServers cloud that receives them.

2. What the app does and does not collect

  • No account. The app does not ask you to sign up or log in.
  • No telemetry. The app does not send analytics about your servers, worlds or how you use it.
  • Update checks. The app asks GitHub Releases whether a newer version exists. That request goes to GitHub, not to us, and carries nothing that identifies you.
  • Mod and plugin searches. Searching Modrinth sends your search text to Modrinth’s public API, the same as visiting modrinth.com.
  • Optional tunnel. If you turn on a tunnel so friends can join from outside your network, your server address is relayed by the tunnel provider you choose.

3. This website

The site sets no analytics or advertising cookies. The downloads page asks the GitHub API for the list of releases, so GitHub sees that request. Pages load fonts from Google Fonts.

4. Bug reports

The “Report a problem” tool builds a zip file on your computer. It hides your user name, computer name and network addresses. Nothing is sent unless you attach the file to a message yourself.

5. Your rights

Because we do not hold personal data about you, there is nothing to access or delete on our side. If you think we do hold some, write to contact@kiqa-dev.it.

6. Changes

If this policy changes, the date at the top changes with it.
