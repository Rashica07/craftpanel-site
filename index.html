From nothing to a running server in three steps

No Java install, no batch files and no port forwarding guide to read first.

01

Choose a version

Vanilla, Paper, Fabric, Forge or NeoForge. OMNIServers downloads the server and the right Java for it.

02

Press start

Watch the live console, set the memory with a slider and see CPU and RAM as they happen.

03

Share the address

Copy the address for your network, or open a free tunnel so friends outside your home can join.

Everything a server needs, in one place

Every feature is free. There is no premium tier and no locked themes.

Performance graphs

CPU, memory and uptime for the running server, over the last minute up to four hours.

Backups and snapshots

Scheduled backups with retention, a safety snapshot before risky changes, and restore in a click.

Live console

Run commands, filter output and keep the log.

Worlds

Import a world by dragging it in, export it, or swap the active one.

Players

Op, whitelist and ban from a list instead of commands.

Mods and plugins

Install and update from inside the app.

App lock

Protect the app with a PIN when you share a computer.

Free tunnel

Let friends join from anywhere without touching your router.

Questions

Is it really free?

Yes. Every feature and every theme is included. There is no premium tier, no trial and no key to enter.

Do I need an account?

No. OMNIServers runs on your computer and does not ask you to sign up for anything.

Will it work on Linux?

A Linux build is in progress. It is not released yet, so for now OMNIServers is available for Mac and Windows.

I used CraftPanel. Is this the same app?

Yes. CraftPanel is now called OMNIServers. Your servers, worlds and settings stay where they were and the app updates in place.

Where can I get help?

Join the Discord. The invite never expires and you get the member role as soon as you join.

Where are my worlds stored?

In a folder on your own computer. You can open it from the app at any time.
