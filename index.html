Features

Everything a small server needs, nothing it doesn't

Built for the person running the server for their friends, not a hosting company's ops team.

One-click setup

Vanilla, Paper, Spigot, Fabric, Forge, NeoForge, or Bedrock — CraftPanel fetches the right files and configures the port, RAM, and Java for you.

One-click modpacks

Search Modrinth, pick a pack. Loader and Minecraft version come from the pack itself — nothing to match up by hand.

A real console

Live logs, RCON commands, broadcasts, whitelist and ops — everything you'd SSH in for, in one window.

Signed auto-updates

CraftPanel checks, downloads, and installs its own updates from Settings. No reinstalling by hand.

Scheduled backups

Local backups on a schedule, restorable in one click — snapshots and zip exports, kept on your own machine.

Share it in one link

A join address and QR code, generated the moment your server's up — no port-forwarding explainer required.

How it works

Three steps, start to finish

01

Pick a flavour

Vanilla, Paper, Spigot, Fabric, Forge — or search for a modpack instead. CraftPanel downloads the right files for you.

02

Press Start

No config files, no Java flags, no terminal. It just boots — and CraftPanel offers to install Java itself if you don't have it.

03

Send the address

One click makes a link — and a QR code — your friends can join from anywhere.
